# 문서 표현 규칙 (BRD v3.0.0의 구분을 유지)

- 목표·가정·실측을 섞지 않는다. BRD의 수치(3~5 N, 0.5 mm, 30 N, 5 mm, 40 ms 등)는 설계 출발값이다. 실측값을 적을 때는 날짜·조건·측정자를 같이 적는다.
- 확인 수준 4단계를 구분한다: 매뉴얼 설명[E10] / 소스 확인[E18] / 실제 PC 호출 확인[E19] / 실기 성능 검증. 앞 단계를 뒤 단계로 올려 적지 않는다.
- 시험 항목을 적는 것은 시험 완료가 아니다. 결과가 없으면 "미실시"로 둔다.
- MVP 결과물은 "외곽 엣지·경로 후보"다. 실제 용접 이음이나 실행 가능한 용접 경로로 표현하지 않는다.
- RG2 쐐기·폭 변화 방식은 범위 밖이다. 구현·실험 계획으로 다시 넣지 않는다.
- `docs/BRD.md`는 직접 고치지 않는다. 변경은 팀 합의 후 새 버전으로 교체한다.
