# 단위·좌표 기준

상태: **미확정**. BRD 6장에 따라 물품 도착·환경 세팅 후 학민이 확정한다(T02, T03). 확정 전까지 아래 값을 코드에 상수로 넣지 않는다.

## 단위
| 구간 | 길이 | 각도 | 힘 | 상태 |
|---|---|---|---|---|
| 두산 API (posx, get_tool_force) | mm | deg | N | 매뉴얼 기준 |
| ROS 내부 (자체 인터페이스) | m | rad | N | BRD 제안, T01에서 확정 |
| MQTT·웹 | mm | TBD | N | BRD 제안, T01에서 확정 |

변환 위치: 두산↔ROS는 robot_manager, ROS↔웹은 mqtt_bridge. 그 외에서는 변환하지 않는다.

## 미결정 (BRD 6장, 팀 확인 없이 정하지 않는다)
홈 복귀 경로·순서, 중단 위치 재접근 절차, 이상 상태별 재시작 허용 조건, 정지 우선순위·래치 해제 조건, 데이터 최신성 한계, heartbeat 만료 정책.
