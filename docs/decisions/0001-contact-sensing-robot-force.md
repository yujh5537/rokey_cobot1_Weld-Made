# ADR-0001: 접촉 판정은 로봇 내장 힘 감지(robot_force)로 한다

- 날짜: 2026-09-18 / 근거: BRD v3.0.0 1.4절 / 상태: 채택

## 결정
RG2는 탐침을 고정 파지하는 데만 쓴다. 접촉 발생은 `get_tool_force()`의 기준값 대비 외력 임계, 접촉 소실은 누름 상태의 z 급강하(주)와 외력 감소(보조)로 판정한다. 개발·리허설용으로 sim 입력원을 병행한다.

## 범위 밖
RG2 쐐기·폭 변화 방식은 가정값 기반 이론 검토만 했고 실험 이력이 없다. 구현·실험 계획도 없다.

## 아직 검증되지 않은 것
M0609의 3~5 N 접촉 검출 성능은 실기 검증 이력이 없다(TR-01에서 측정). `set_external_force_reset()`의 ROS 2 Python 노출, `drl_script_run()` 경유 리셋, `motion/move_stop` 연결은 `docs/env/api-check-log.md`에서 관리한다.
