## 1. 설계 원칙

1. **실기 로봇 명령은 사람이 직접 실행한다.** Claude 는 sim · Virtual 만 돌린다(CLAUDE.md 규칙 1).
2. **같은 임계값을 두 곳에서 본다**(계약 7.2). 과대 외력 30 N 은 contact_detector 와 safety_monitor 가,
   하강 제한 5 mm 는 robot_manager 와 safety_monitor 가 각각 본다. `test_config.py` 가 두 값이 같은지 검사한다.
3. **모르면 안전하다고 하지 않는다.** 해제 호출이 실패하면 `compliance_released=false` 로 사실대로 보고하고,
   정지를 확인하지 못하면 정지 요청을 지우지 않아 다음 goal 을 계속 거절한다(#113).
4. **입회자가 비상정지 앞에 선다.** 실기 세션 내내.

## 4. 세션 시작 점검표 (실기 때마다)

- [ ] 입회자가 **비상정지 앞에** 선다
- [ ] `sodreal` 로 브링업. 로그에 `mode : real` 확인
- [ ] **툴 · TCP 등록**: `python3 docs/env/apply_tool_tcp.py --tcp-x 0 --tcp-y 0` → `OK: ... [0.0, 0.0, 252.12]`
      — `--tcp-x 0 --tcp-y 0` 를 빼면 옛 값 `(−1.30, 3.71)` 이 들어가 팁이 3.9 mm 밀린다
- [ ] **탐침 상태**: 홀더 경계에 그은 선이 그대로인지 눈으로. 같은 각도로 사진 1 장
- [ ] **기준점 접촉**으로 z 대조: (524.97, −172.03) 을 힘 접촉(증분 3 N)해 판정 z 가 **95.006 ± 0.3 mm** 인지
- [ ] 무접촉 \|F0\| 가 **1~2 N** 인지(12 N 이면 툴 미등록)
- [ ] `real.yaml` 의 `over_force_n` 30 · `drop_limit_m` 0.005 · `sample_stale_ms` 500 확인
- [ ] launch 로그를 `tee` 로 남긴다 — 9/23 TR-01 에서 로그가 없어 임계값을 파일로 증명하지 못했다

## 5. 시연 중 규칙

- 파라미터를 **바꾸지 않는다**(`sample_stale_ms` 포함).
- `Ctrl+C` 로 노드를 끄지 않는다(정지 · 해제 없이 죽는다. 안전 감사 C-1).
- 래치가 두 번 연속 걸리면 그 회차는 **sim 백업 영상으로 전환**한다.
- 실기 명령은 사람이 친다.
