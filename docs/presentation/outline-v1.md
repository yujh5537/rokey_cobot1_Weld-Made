## 고정 레이아웃이 있는 슬라이드
- **04-⑥ KPI 표** 열: 항목 · KPI 기준(BRD 9 장) · 실측값(출처) · 판정(달성 / 미달 / 미실시) · 미달 원인 · 개선안. 행: 치수 오차 ±3 mm · 검출 하중 ≤ 5 N · 작업 중지 반응 ≤ 1 s · 관제 반영 지연 ≤ 200 ms(TR-05) · 전체 탐색 시간 ≤ 120 s · 실기 연속 성공. 미달은 숨기지 않는다(초기 KPI 이해 부족 → 정밀도 우선으로 시간 기준을 포기 → 원인 → 극복 → 개선안).
- **04-⑦ 평가 항목 대응표** 열: 평가 항목(완전성 · 정확성 · 안정성 · 입출력 · 지속성) · 우리가 한 것 · 증거(슬라이드 번호 · 문서 · 시험 보고). `docs/deliverables/README.md` 5 절이 뼈대.
- **04-⑧ 문제와 해결** (1 인 1 장) 4 칸 고정: 증상(사진 · 그래프) → 원인 → 조치(PR) → 결과 수치. 제목은 "무엇을 어떻게 고쳤다" 한 문장.
- **[뺄 수 있음]** 블록은 다른 슬라이드에서 참조하지 않는다(용접을 빼도 01-② · 03 일정표 · 04 가 그대로 읽힌다). 용접 관련은 01-② 마지막 불릿 · 03 일정표 phase 2 행 · 04-⑨ · 04-⑩ 컷, 네 곳뿐이다.

## 슬라이드 작성 규칙
- 한 장 = 주장 한 문장(제목) + 그림 · 표 1 개 + 글머리 3 줄 이하. 발표 대사는 노트에 3~5 문장.
- 수치마다 출처(보고서 · PR 번호)를 하단에 작게. 실측 · 설계 출발값 · 계산값을 구분.
- 그림은 png 로 넣고 원본(drawio · 캡처)은 `docs/presentation/assets/<파트>/` 에.
- Claude Code 사용은 언급하지 않는다. 이슈 · PR 개수 · 목록은 넣지 않는다. 근거 각주로 `PR #127` 처럼 건별 한 개는 허용.
- 파일: `slides-<이름>.pptx`(hakmin · hyunji · euiseok · byeonghu). 표지 · 목차 · 양식 안내 장은 지우고 보낸다. 글꼴 · 크기 · 색은 템플릿 그대로.
