# 발표 자료

| 파일 | 내용 |
|---|---|
| `outline-v1.md` | 목차 · 슬라이드 배분 · 작성 규칙 (병후 확정 2026-09-24) |
| `template.pptx` | 결과보고서 양식에서 안내 2 장을 지우고 표지(weld-made · 박병후 · 김학민 · 남현지 · 정의석 · 멘토 이일주)를 채운 사본. **복사해서** `slides-<파트>.pptx` 로 자기 파트만 만든다. 3~10 장은 양식의 장별 안내 · 예시라 참고만 하고 지운다 |
| `slides-<파트>.pptx` | 각자 파트 (학민 · 현지 · 의석 · 병후) |
| `assets/<파트>/` | 그림 원본(drawio · png · 캡처 · 영상 클립) |

합치기: 병후가 `결과보고서_weld-made(접촉 탐색 용접선 스캔 · 용접).pptx` → pdf. 제출 파일명은 `docs/deliverables/README.md` 1 절.
