### 🔴 원인: `dsr01_emulator` 컨테이너가 죽어 있었다
`sodvir` 의 launch 프로세스는 살아 있는데 **에뮬레이터 컨테이너가 없었다**(`docker ps` 빈 출력. `--rm` 이라 흔적도 남지 않는다).
그 상태에서는 `dsr_controller2` 노드는 떠 있고 서비스 이름도 다 보이지만 **모든 호출이 무응답**이다. bringup 을 전부 내린 뒤 `ros2 service call` 로 직접 불러도 30초 무응답이었다.

**이것이 9/20 `descend_01.csv` 의 "시간 초과 32회"(PR #80)와 같은 증상일 수 있다.** 그때는 드라이버 버그로 추정했는데, 에뮬레이터 미기동으로도 같은 모양이 나온다. 실기에서는 다른 원인일 수 있으므로 구분해서 봐야 한다.

- **1차로 죽은 것은 현지의 실수다.** 드라이버 확인 중에 `pkill -f "bringup.launch.py"` 를 썼는데, `sodvir`(`m0609_rg2_bringup/bringup.launch.py`)도 같은 패턴에 걸린다. 이후로는 `source:=sim` 으로 좁혔다
- 2차로 죽은 원인은 확인하지 못했다. 컨테이너가 남지 않아 로그를 볼 수 없다

### 📌 통합 절차에 추가
```bash
sod && sodvir
docker ps        # dsr01_emulator 가 보여야 한다. 없으면 드라이버는 무응답이다
```
그리고 자체 노드만 내릴 때는 **`pkill -f "source:=sim"`** 을 쓴다. `bringup.launch.py` 로 죽이면 `sodvir` 도 같이 죽는다.

## 3. 🔴 잡은 결함: safety_monitor 가 기동하자마자 래치를 걸었다 (#99)
```
[safety_monitor] SAMPLE_STALE: 508 ms 동안 수신 없음 (> 500 ms)
[safety_monitor] /robot/stop 서버가 없다. robot_manager 가 떠 있는지 확인한다
[safety_monitor] 정지 요청이 0.6 s 안에 확인되지 않았다 … 물리 비상정지를 눌러야 한다
```
두 노드의 **보수적 기본값이 겹친** 결과다.
1. 노드 5개가 동시에 뜨면서 샘플이 508 ms 끊겼다(`sample_stale_ms` 500 초과)
2. 그때 robot_manager 는 `moving=true` 였다 — "위치를 모르면 이동 중"(#72). 기동 직후엔 위치 이력이 없으니 당연하다
3. safety_monitor 의 "움직이는 중이면 최신성 조건도 STOP" 이 걸려 래치
4. `/robot/stop` 서버도 아직 없어 `UNCONFIRMED` 까지 올라갔다

`startup_grace_s`(3.0 s)를 넣어 고쳤다. **과대 외력 · 하강 제한은 유예하지 않는다.** 고친 뒤 기동 직후 `level=0`, 래치 없음을 확인했다.

## 5. 오늘 오전 실기 (T30 · T31) — 첫 순서는 탐침 밀림 확인
PR #80 에서 탐침이 홀더 안으로 밀리고 있을 가능성이 나왔다(80분 사이 0.6 → 1.3 mm). **사실이면 그 세션에서 찍은 z 관련 값이 전부 무효다.**

절차:
1. **탐침과 그리퍼 핑거 경계에 펜으로 선을 긋고, 같은 각도로 사진 한 장**
2. 같은 점을 같은 누름 힘(4.5 N)으로 **30초 간격 5회**, 각 회차 시각 기록
   (밀림이 누름 횟수에 비례하는지 시간에 비례하는지가 갈린다 — 대응이 다르다)
3. **끝나고 같은 각도로 사진 한 장.** 0.2~0.3 mm 는 선만으로는 판단이 갈린다. 사진이 유일한 시각 증거다
4. **밀림 확인 결과가 나오기 전에는 다음 단계로 넘어가지 않는다**

그다음 항목: 9/19 작업대 두 점 재측정(작업대 z 가 99.6 인지 100.6 인지 갈린다) · 180° 회전 x · y 확인 · 편향–힘 3점(3 · 5 · 7 N) · 4방향 부호 확인 · 하강–접촉 연속 기록(9/20 `descend_01.csv` 는 z 가 0.06 mm 만 움직여 실패했다).

**2인 1조. 한 사람은 물리 비상정지 버튼에 손을 얹고 화면이 아니라 로봇을 본다.**
9/20 세션은 입회자 없이 진행됐고 같은 세션에서 조회 시간 초과가 32회 있었다(`TR-01_20260920.md`).
