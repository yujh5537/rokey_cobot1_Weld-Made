## 4. sim 종단 실행 — **미실시**
Virtual Mode(`sodvir`) 기동은 사람이 해야 한다(CLAUDE.md 규칙 1). 오늘은 거기까지 가지 못했다.

대신 **드라이버 없이 launch만 띄워** 어느 노드가 뜨는지 확인했다(`ROS_DOMAIN_ID=41`).
```bash
ros2 launch contact_scan_bringup bringup.launch.py source:=sim
```
| 조건 | 뜬 노드 | 죽은 노드 |
|---|---|---|
| `sod` 없음 | `contact_detector` · `safety_monitor` · `scan_manager` | `robot_manager`(`ModuleNotFoundError: dsr_msgs2`) · `mqtt_bridge`(`paho`) |
| **`sod` 있음** | `contact_detector` · `safety_monitor` · `scan_manager` · **`robot_manager`** | `mqtt_bridge`(`paho`) |

- 네 노드가 각자 `sim.yaml` 값으로 기동하는 것을 로그로 확인했다
- `safety_monitor`가 `/safety/status`를 발행한다(`level=0`, `position`은 NaN + `position_valid=false`)
- `contact_detector`는 `source=sim`에서 "가상 직육면체는 아직 없다"를 경고로 남긴다(T07 남은 범위)
- **`/robot/sample`이 실제로 흐르는지, 5점 탐색이 도는지는 확인하지 못했다.** 두산 드라이버(Virtual)가 필요하다

### 📌 통합 절차에 추가할 것
1. `bringup.launch.py`를 돌리는 터미널에도 **`sod`가 필요하다**(robot_manager가 `dsr_msgs2`를 import한다). `contact_scan_bringup/README.md`에 반영 예정
2. 클린 빌드 전에 **`rosdep install`**
