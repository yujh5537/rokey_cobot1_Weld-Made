# docs 안내

여기에는 **잘 바뀌지 않는 지식**만 둔다. 일정·담당·진행 상태는 GitHub Issues와 Milestones(M1~M5)가 기준이다.

| 경로 | 내용 | 바꾸는 방법 |
|---|---|---|
| `BRD.md` | 비즈니스 요구사항 v3.2.0 (기준 문서) | 직접 수정 금지. 팀 합의 후 새 버전으로 교체 |
| `architecture.md` | 노드 책임, 배치, 데이터 흐름 | 구조가 바뀌는 PR에서 같이 |
| `design/` | 인터페이스 정의서, 노드 구성도, 아키텍처 그림의 최신본 (참고 자료. 계약과 다르면 계약이 우선) | 새 버전 파일로 교체하고 이전 버전은 삭제 |
| `contracts/` | ROS 인터페이스, MQTT 스키마, 단위·좌표 기준 | 필수 리뷰 (CODEOWNERS) + CHANGELOG |
| `decisions/` | 결정 기록(ADR). 무엇을 왜 정했는지 | 결정할 때마다 1장 추가, 기존 것은 고치지 않고 대체 |
| `env/` | 환경 구축 기록, 버전, API 호출 확인 로그 [E19] | 확인한 사람이 바로 |
| `test-reports/` | TR 시험 결과, 저녁 통합 기록 | 시험한 사람이 바로 |
| `conventions.md` | 브랜치·커밋·PR·리뷰 규칙 | 필수 리뷰 |
| `archive/` | 초기 엑셀 일정표, BRD v3.1.0 docx 원본(동결본). 갱신하지 않는다 | - |
